# 📁 Cisco Packet Tracer Lab Files (`.pkt`)

This directory is designated for the binary Cisco Packet Tracer lab project file (`.pkt`).

---

## 🛠️ How to Load or Save the Lab in Packet Tracer

1. **Compatible Version:**
   - Cisco Packet Tracer **v8.0**, **v8.1**, **v8.2**, or newer.
   - Download official Packet Tracer from [Cisco Networking Academy (Skills for All)](https://www.netacad.com/).

2. **File Placement:**
   - Save your final working Packet Tracer lab file in this directory as:
     `packet-tracer/enterprise_factory_network.pkt`

3. **Deploying Configurations to Devices:**
   - Follow the step-by-step physical cabling guide in [`docs/PACKET_TRACER_LAB.md`](../docs/PACKET_TRACER_LAB.md).
   - Use the ready-to-deploy `.ios` and `.cfg` files from the [`configs/`](../configs/) directory.
   - For complete console logs and verification commands, reference [`docs/CLI_EXECUTION_AND_VERIFICATION_LOGS.md`](../docs/CLI_EXECUTION_AND_VERIFICATION_LOGS.md).

4. **Visual Demonstrations:**
   - Screenshots of the topology and CLI verification outputs are stored in [`docs/screenshots/`](../docs/screenshots/).
