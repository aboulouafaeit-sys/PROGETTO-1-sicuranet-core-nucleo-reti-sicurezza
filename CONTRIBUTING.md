# Contributing Guidelines

Thank you for your interest in contributing to this project!

## How to Contribute
1. Fork the repository on GitHub.
2. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Test any Cisco IOS configurations inside Cisco Packet Tracer before submitting.
4. Commit your changes with clear, descriptive commit messages:
   ```bash
   git commit -m "Add new QoS policy configuration for VoIP"
   ```
5. Push to your branch and open a Pull Request.

## Issues and Feedback
Please open a GitHub Issue for any questions, suggestions, or bug reports regarding the network topologies or configuration files.
