# مشروع شبكة مؤسسية ذكية (شركة ومصنع متكامل)
## Enterprise & Smart Factory CCNA Project

مشروع شبكات متكامل يعتمد على التقسيم الهيكلي، العزل الأمني (VLANs)، وتوفير جودة الخدمة (QoS) للوسائط المتعددة (صوت، فيديو، بيانات، شاشات ذكية، وسيرفرات).

---

## 1. محتويات وتجهيزات المشروع

| الجهاز | الدور في الشبكة | التقنية المستخدمة |
| :--- | :--- | :--- |
| **Edge Router / Firewall** | توفير حماية الشبكة، NAT/PAT، والربط بالإنترنت | Cisco 2911 / 4331 Router أو ASA Firewall |
| **Core / Distribution Switch** | التوجيه بين الشبكات (Inter-VLAN Routing) وتجميع الحزم | Cisco Catalyst 3560 / 3650 L3 Switch |
| **Access PoE Switches** | توزيع المنافذ وتغذية الأجهزة بالطاقة (PoE) | Cisco Catalyst 2960-24PC-L |
| **Cisco IP Phones** | الاتصال الصوتي المكتبي والإنتاجي | Cisco IP Phone 7960 (مع PoE مدمج) |
| **Access Points (APs)** | توفير تغطية Wi-Fi للموظفين والزوار | Cisco Aironet / Lightweight APs |
| **Data Center Servers** | خوادم مركزية (AD, DNS, DHCP, Web, File) | Cisco Generic Servers |
| **Smart TVs & IoT Displays** | شاشات عرض لوحات الإنتاج والمراقبة (Dashboard) | Smart Display / IoT Thin Clients |
| **Computers (PCs / Laptops)** | أجهزة عمل الموظفين والمهندسين | Desktops / Laptops |

---

## 2. جدول توزيع العناوين والـ VLANs

| VLAN ID | الاسم (Name) | الشبكة (Network) | البوابة (Gateway) | الوظيفة |
| :---: | :--- | :--- | :--- | :--- |
| **10** | Management | 192.168.10.0/24 | 192.168.10.1 | إدارة الأجهزة عن بعد (SSH / Telnet) |
| **20** | Admin_Data | 192.168.20.0/24 | 192.168.20.1 | بيانات حواسيب الموظفين والإدارة |
| **30** | VoIP_Voice | 192.168.30.0/24 | 192.168.30.1 | المكالمات الصوتية المشفرة ذات الأولوية |
| **40** | Corp_WiFi | 192.168.40.0/24 | 192.168.40.1 | الشبكة اللاسلكية للموظفين |
| **50** | Servers_DC | 192.168.50.0/24 | 192.168.50.1 | خوادم الشركة والملفات وقواعد البيانات |
| **60** | Factory_IoT | 192.168.60.0/24 | 192.168.60.1 | الشاشات الذكية (Smart TVs) وماكينات المصنع |

## 3. طريقة الربط الذكي بين الحاسوب وهاتف الـ IP (VoIP Daisy Chaining)

هواتف الـ IP من سيسكو تتيح توصيل الهاتف بالحاسوب عبر كابل واحد إلى الجدار:
1. يخرج كابل من سويتش الـ PoE إلى منفذ **SW** في ظهر الهاتف.
2. يخرج كابل ثانٍ من منفذ **PC** في الهاتف إلى كرت شبكة الحاسوب.
3. يقوم السويتش تلقائياً بعزل الصوت على **VLAN 30** مع علامة 802.1Q، ويمرر بيانات الحاسوب على **VLAN 20** بدون Tag.
